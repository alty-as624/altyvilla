# 生活誌

個人生活資訊 dashboard,示範架構。

## 部署步驟(GitHub + Vercel)

1. 去 github.com 開個免費account(如未有)
2. 開一個新repository,叫 `life-info`
3. 將呢個資料夾入面所有檔案上傳去個repository
   (最簡單方法:GitHub網頁版有「uploading an existing file」按鈕,直接拖曳上去)
4. 去 vercel.com,用GitHub account登入(免費)
5. 揀「Add New Project」,連去你剛開嘅 `life-info` repository
6. Vercel會自動偵測係Next.js project,直接按「Deploy」就得
7. 幾分鐘後會俾你一個 `xxx.vercel.app` 網址,開得到就代表成功
